# 알림 시스템 구현 완료 가이드 🔔

## 구현된 기능

### 1. 좋아요 알림 ❤️
- 다른 사용자가 내 후기에 좋아요를 누르면 알림이 생성됩니다
- 알림 메시지: "{사용자명}님이 회원님의 "{후기 제목}" 후기를 좋아합니다."
- 자기 자신의 글에 좋아요를 누른 경우 알림이 생성되지 않습니다
- 좋아요 취소 시 해당 알림도 자동으로 삭제됩니다

### 2. 댓글 알림 💬
- 다른 사용자가 내 후기에 댓글을 작성하면 알림이 생성됩니다
- 알림 메시지: "{사용자명}님이 "{후기 제목}" 후기에 댓글을 남겼습니다: "{댓글 내용 미리보기}""
- 자기 자신의 글에 댓글을 단 경우 알림이 생성되지 않습니다
- 댓글 내용은 30자까지 미리보기로 표시됩니다

### 3. 여행 일정 알림 ✈️
- 다가오는 여행 일정이 있을 때 자동으로 알림이 생성됩니다
- 알림 생성 시점: 여행 시작 14일 전, 7일 전, 3일 전
- 알림 메시지: "{여행 제목} 일정이 {N}일 남았습니다. 준비물 챙기셨나요?"
- 중복 알림 방지 기능 포함

### 4. 알림 관리 기능
- ✅ 읽음/안읽음 상태 표시
- 🗑️ 개별 알림 삭제
- 🗑️ 전체 알림 삭제
- ✔️ 개별 알림 읽음 처리
- ✔️ 전체 알림 읽음 처리
- 🔄 30초마다 자동 새로고침

## 데이터베이스 설정

### 1. Supabase SQL Editor에서 실행
`database/notifications_schema.sql` 파일의 SQL을 Supabase SQL Editor에서 실행하세요.

이 스크립트는 다음을 생성합니다:
- `notifications` 테이블
- 성능 향상을 위한 인덱스
- Row Level Security (RLS) 정책
- 자동 업데이트 트리거
- 좋아요/댓글 수 자동 증가/감소 트리거

### 2. 필요한 테이블 컬럼 확인
다음 테이블에 필요한 컬럼이 있는지 확인하세요:

**community_posts 테이블:**
- `like_count` (INTEGER, DEFAULT 0)
- `comment_count` (INTEGER, DEFAULT 0)

만약 없다면 다음 SQL을 실행하세요:
```sql
ALTER TABLE community_posts 
ADD COLUMN IF NOT EXISTS like_count INTEGER DEFAULT 0,
ADD COLUMN IF NOT EXISTS comment_count INTEGER DEFAULT 0;
```

## 사용 방법

### 1. 알림 확인
1. 마이페이지로 이동
2. "알림" 메뉴 클릭
3. 읽지 않은 알림은 파란색 점으로 표시됩니다
4. 알림을 클릭하면 읽음 처리됩니다

### 2. 알림 생성 테스트

#### 좋아요 알림 테스트:
1. 사용자 A로 로그인하여 커뮤니티에 후기 작성
2. 사용자 B로 로그인
3. 사용자 A의 후기에 좋아요 클릭
4. 사용자 A의 마이페이지 > 알림에서 확인

#### 댓글 알림 테스트:
1. 사용자 A로 로그인하여 커뮤니티에 후기 작성
2. 사용자 B로 로그인
3. 사용자 A의 후기에 댓글 작성
4. 사용자 A의 마이페이지 > 알림에서 확인

#### 여행 일정 알림 테스트:
1. 마이페이지 또는 PlanLab에서 여행 일정 생성
2. 시작일을 3일, 7일, 또는 14일 후로 설정
3. 마이페이지 > 알림에서 자동 생성된 알림 확인

## 알림 타입별 아이콘

- ❤️ **좋아요**: 빨간색 하트 아이콘
- 💬 **댓글**: 초록색 말풍선 아이콘
- 📅 **여행 일정**: 파란색 캘린더 아이콘

## 시간 표시 형식

- 1분 미만: "방금 전"
- 1시간 미만: "N분 전"
- 24시간 미만: "N시간 전"
- 7일 미만: "N일 전"
- 7일 이상: "YYYY. MM. DD" 형식

## 주요 특징

### 실시간 업데이트
- React Query를 사용하여 30초마다 자동으로 새 알림을 확인합니다
- 알림 생성 후 즉시 반영됩니다

### 중복 방지
- 같은 여행 일정에 대해 같은 시점의 알림은 한 번만 생성됩니다
- 좋아요 취소 시 알림도 함께 삭제됩니다

### 보안
- Row Level Security (RLS)로 사용자는 자신의 알림만 볼 수 있습니다
- 다른 사용자의 알림에 접근할 수 없습니다

## 트러블슈팅

### 알림이 생성되지 않는 경우:
1. Supabase SQL Editor에서 `notifications_schema.sql` 실행 확인
2. 브라우저 콘솔에서 에러 메시지 확인
3. Supabase 대시보드에서 RLS 정책 확인

### 알림이 표시되지 않는 경우:
1. 로그인 상태 확인
2. 브라우저 새로고침
3. 개발자 도구 > Network 탭에서 API 호출 확인

### 여행 일정 알림이 생성되지 않는 경우:
1. 여행 시작일이 3일, 7일, 또는 14일 후인지 확인
2. 마이페이지를 새로고침하여 알림 생성 트리거
3. `createTripNotifications` 함수 실행 확인
